## What it does

- Browse available groups
- Compare spreadsheet rosters and export results
- Explicit confirmation for member-management actions

## Quick start

**Requirements:** Chrome or Edge 111+ and your own WhatsApp Web session.

```powershell
npm test
```

## Before you run

Load this folder using chrome://extensions → Developer mode → Load unpacked. No npm install is needed for normal use. No contact spreadsheet is included. WhatsApp internal APIs can change; this is an unofficial extension. Only process contacts and groups you are authorized to manage.
